# Skywall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GNOME wallpaper, re-rendered once a minute, showing a star chart of the sky the monitor faces, with a settings window and an "Open in Stellarium" hand-off.

**Architecture:** A run-once `skywall render` command (Skyfield → stereographic projection → Cairo PNG → gsettings), fired every minute by a systemd user timer. A libadwaita settings app edits a TOML config. `skywall open` writes a Stellarium startup script and launches the Stellarium Flatpak aimed at the same view.

**Tech Stack:** Python 3.11 (`/usr/bin/python3`, venv with `--system-site-packages` for PyGObject/pycairo), Skyfield, NumPy, pygeomag, tomli-w, GTK4 + libadwaita 1.2, systemd user units, pytest.

**Spec:** `docs/superpowers/specs/2026-11-22-skywall-design.md`

## Global Constraints

- Project root `~/skywall`; package `skywall/`; tests `tests/`; venv `~/skywall/.venv` created with `/usr/bin/python3 -m venv --system-site-packages .venv`. Never use the pyenv `python3`.
- Config `${XDG_CONFIG_HOME:-~/.config}/skywall/config.toml`; data `${XDG_DATA_HOME:-~/.local/share}/skywall/`. Every function that touches either takes the path as a parameter, defaulting to these, so tests use `tmp_path`.
- Every function that runs an external command (`gsettings`, `systemctl`, `flatpak`) takes a `runner: Callable[[list[str]], str]` parameter (default: `subprocess.run(..., check=True, capture_output=True, text=True).stdout`), so tests use a fake runner that records calls.
- Output image: `width`×`height` from config, default **3440×1440**.
- Defaults: facing **296.0**, reference **"magnetic"**, tilt **0.0**, FOV **60.0** (horizontal), magnitude limit **6.5**. FOV is clamped to 20–180, tilt to −90…90, facing normalised to [0, 360).
- Refraction off. No network except the one-time Skyfield/Hipparcos downloads. Location never leaves the machine.
- No decorative or random stars: every drawn object is at its computed position.
- Turning live wallpaper off restores the user's previous wallpaper. Never write an empty URI.
- Steady-state `skywall render` must take under 1 s wall time (measured in Task 7).
- `.gitignore` includes `.venv/`, `.superpowers/`, `__pycache__/`, `*.png`.

## Review Focus

1. **Location not set** (fresh install, or Stellarium's location is `auto`). `skywall render` should exit 2 with "location not set — run skywall settings" and leave the wallpaper alone. → test in Task 7.
2. **Facing wraps past 360°** (e.g. 355° magnetic + 8° declination). Expect 3°, not 363°. → test in Task 3.
3. **Constellation line with one end behind the viewer or off the projection.** The segment is skipped, not drawn as a streak across the screen. → test in Task 6.
4. **No network on first run / download fails.** Exit 3, previous wallpaper untouched, message on stderr. → test in Task 7.
5. **The user already has custom GNOME keyboard shortcuts.** Installing Skywall's shortcut must keep theirs, and re-running install must not add a duplicate. → test in Task 9.

### Task 2: Stereographic projection

**Files:**
- Create: `skywall/projection.py`
- Test: `tests/test_projection.py`

**Interfaces:**
- Produces: `class StereographicProjection(center_az_deg: float, center_alt_deg: float, hfov_deg: float, width: int, height: int)` with
  - `project(az_deg: float, alt_deg: float) -> tuple[float, float] | None`
  - `project_many(az_deg: np.ndarray, alt_deg: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray]` (x, y, valid mask)
  - property `vfov_deg: float`
- Math (azimuth = longitude λ, altitude = latitude φ, centre λ0, φ0):

```
cos c = sin φ0 sin φ + cos φ0 cos φ cos(λ−λ0)
k     = 2 / (1 + cos c)
X     = k cos φ sin(λ−λ0)                              # east of centre → right
Y     = k (cos φ0 sin φ − sin φ0 cos φ cos(λ−λ0))      # up
s     = (width/2) / (2 tan(hfov/4))                    # px per unit
x = width/2 + X·s ;  y = height/2 − Y·s
invalid when c > 170°
vfov  = 4 · atan((height/width) · tan(hfov/4))
```

### Task 6: Star-chart renderer

**Files:**
- Create: `skywall/render.py`
- Test: `tests/test_render.py` (no network: builds `SkyScene` objects by hand)

**Interfaces:**
- Consumes: `SkyScene`, `Body` (Task 5), `Constellation` (Task 4), `StereographicProjection` (Task 2), `Config` (Task 1).
- Produces: `render_sky(scene: SkyScene, constellations: list[Constellation], proj: StereographicProjection, cfg: Config) -> cairo.ImageSurface`, plus module constants `BACKGROUND = (0.012, 0.016, 0.04)` and `BELOW_HORIZON_TINT = (0.03, 0.04, 0.03, 0.35)` (RGBA overlay). Any other styling is the builder's call, within the spec's "Look" section.
- Draw order: background → below-horizon tint (fill between the projected alt=0 polyline and the bottom edge; skip the tint when the horizon doesn't cross the screen left to right) → constellation lines → stars → bodies → labels → horizon line with compass labels (N, NE, E, … every 45°, ticks every 15°) → optional timestamp.
- Constellation segment rule: draw only when both endpoints' HIP numbers are in `scene.hip_index` and **both** project valid **and** at least one lands within the image bounds plus a 200 px margin.
- Star radius from magnitude (brighter = bigger, mag 6.5 ≈ 0.6 px, mag −1.5 ≈ 4 px); colour from B−V (NaN → white).

### Task 7: Wallpaper setting and the `render` command

**Files:**
- Create: `skywall/wallpaper.py`, `skywall/cli.py`
- Modify: `tests/conftest.py`: add `FakeRunner(gsettings_values: dict[str, str])`. It is callable with an argv list, records every call in `.calls`, answers `gsettings get <schema> <key>` from the dict, and returns `""` for everything else. Tasks 8 and 9 reuse it.
- Test: `tests/test_wallpaper.py`, `tests/test_cli_render.py`

**Interfaces:**
- Consumes: everything above.
- Produces (`wallpaper.py`):
  - `KEYS = ("picture-uri", "picture-uri-dark", "picture-options")`, schema `org.gnome.desktop.background`
  - `next_wallpaper_path(out_dir: Path) -> Path`: returns `sky-a.png` or `sky-b.png`, whichever wasn't written last (missing counts as oldest).
  - `set_wallpaper(path: Path, runner=...) -> None`: sets both URIs to `path.as_uri()` and options to `zoom`.
  - `save_current(cfg: Config, out_dir: Path, runner=...) -> None`: fills `cfg.saved_wallpaper` with all `KEYS` only if it's empty **and** the current URI isn't inside `out_dir`.
  - `restore(cfg: Config, runner=...) -> None`: sets the saved values back and clears them; no-op when nothing is saved.
- Produces (`cli.py`): `main(argv: list[str] | None = None) -> int`, subcommand `render [--output PATH]`. Exit codes: 0 ok, **2 location not set**, **3 data unavailable**. With `--output`, writes the PNG only; without it, writes to `next_wallpaper_path(DATA_DIR / "wallpaper")` and calls `set_wallpaper`. Testability: `main` reads config/data paths from `SKYWALL_CONFIG` / `SKYWALL_DATA` env vars when they're set.
